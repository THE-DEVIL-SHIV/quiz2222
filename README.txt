TELEGRAM QUIZ JSON CONVERTER BOT
================================
1. Zip extract karein.
2. Host par saari files upload karein.
3. Start command:   python quiz_bot.py
   (Build/Install command, agar host maange:  pip install -r requirements.txt)
4. Telegram me bot ko /start bhejein, PDF ya text bhejein, phir /convert.

Keys: BOT_TOKEN aur GEMINI_API_KEY quiz_bot.py ke upar (CONFIG) me hain.
Ya host ke Environment Variables me BOT_TOKEN / GEMINI_API_KEY daal sakte hain.

Zaroori: ek token par sirf ek hi bot instance chalayein.
Scanned ya purane Hindi font wale PDF ke liye /ocr_on use karein.
